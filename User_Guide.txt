=========================================================
                 EDUTRACK USER GUIDE
             Student Management System
=========================================================

1. ABOUT EDUTRACK
---------------------------------------------------------
EduTrack is a Flask and PostgreSQL student management
application. It stores student records and subject marks,
calculates averages and grades, and provides academic
performance summaries.

The project also includes a command-line interface (CLI).

2. MAIN FEATURES
---------------------------------------------------------
WEB APPLICATION
• Student dashboard and class statistics
• Add, view, edit and delete student records
• Search and sort student records
• Automatic average and grade calculation
• Student analytics and performance charts
• CSV and Excel exports
• Admin-only PDF student result cards
• Admin login and protected management actions
• CSRF protection for form submissions
• Friendly 404, 500 and database-unavailable pages

COMMAND-LINE APPLICATION
• Add students and assign marks
• View subject toppers
• Calculate subject class averages
• Save a CSV-formatted local backup
• Reload the student list without restarting the program

3. TECHNOLOGY
---------------------------------------------------------
• Python
• Flask
• PostgreSQL
• Bootstrap and JavaScript
• Chart.js

• Gunicorn

4. RUNNING THE WEB APPLICATION LOCALLY
---------------------------------------------------------
1. Clone the repository:

   git clone https://github.com/alpha00045/EduTrack.git
   cd EduTrack

2. Create and activate a virtual environment:

   python -m venv .venv

   Windows PowerShell:
   .\.venv\Scripts\Activate.ps1

   macOS/Linux:
   source .venv/bin/activate

3. Install dependencies:

   pip install -r requirements.txt

4. Configure these environment variables. Do not commit
   real credentials or the .env file.

   DATABASE_URL=your_postgresql_connection_string
   SECRET_KEY=your_long_random_secret
   ADMIN_USERNAME=your_admin_username
   ADMIN_PASSWORD=your_strong_admin_password

5. Start the web application:

   python app.py

6. Open:

   http://127.0.0.1:5000

5. USING THE WEB APPLICATION
---------------------------------------------------------
• Open the dashboard to see class statistics and top
  student averages.
• Select Students > View Students to search and sort
  student records.
• Sign in using the configured administrator credentials
  before adding, editing or deleting student records.
• Open a student's details to review marks, average and
  grade.
• Administrators can download the student's PDF result
  card from the details page.
• Use Reports to download CSV/Excel files or open the
  analytics dashboard.

6. RUNNING THE COMMAND-LINE APPLICATION
---------------------------------------------------------
Run:

   python main.py

Menu options:

1. Add Student
2. Assign Grades
3. View Subject Topper
4. View Class Average
5. Save Data Locally
6. Reload
7. Exit

The local backup is written to student_backup.txt in CSV
format. Keep the backup file in a safe location.

7. DATABASE AND ERROR HANDLING
---------------------------------------------------------
EduTrack uses PostgreSQL. Configure the connection with
DATABASE_URL.

If the database is temporarily unavailable, the web
application displays a service-unavailable message. The
application does not display database connection details
to visitors.

8. TESTS
---------------------------------------------------------
Install development dependencies:

   pip install -r requirements-dev.txt

Run the automated test suite:

   python -m pytest -q

GitHub Actions also runs the tests for pushes and pull
requests to the main branch.
