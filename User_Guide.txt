=========================================================
1. ABOUT THE PROJECT
=========================================================

EduTrack is a web-based and command-line Student Performance
Management System designed to help teachers efficiently manage
student records and academic performance.

The system stores all records in a PostgreSQL cloud database,
making the data accessible from anywhere through the deployed
web application.

4. RUNNING THE WEB APPLICATION
=========================================================

1. Install the required packages

   pip install -r requirements.txt

2. Configure the DATABASE_URL environment variable.

3. Start the Flask application

   python app.py

4. Open your browser

   http://127.0.0.1:5000

=========================================================
5. USING THE WEB DASHBOARD
=========================================================

The dashboard allows users to:

• View all registered students
• Add new students
• Monitor student performance
• View dashboard statistics
• Access cloud-stored student records

All data is synchronized with the PostgreSQL database.

=========================================================
6. USING THE CLI APPLICATION
=========================================================

Run

   python main.py

Available Options

1. Add Student
2. Assign Grades
3. Subject Topper
4. Class Average
5. Backup Data
6. Reload Program
7. Exit
