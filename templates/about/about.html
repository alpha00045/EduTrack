About EduTrack

A simple, secure way to manage student records and academic performance.

What EduTrack does

EduTrack is a student management application built with Python, Flask and PostgreSQL. It helps administrators maintain student records, review marks, calculate averages and grades, and understand class performance.

Main features

  • Student record creation, viewing, editing and deletion
  • Search and sorting on the student list
  • Automatic averages and grade calculation
  • Academic analytics and performance charts
  • CSV and Excel report exports
  • Admin authentication and protected management actions

Technology

Python · Flask · PostgreSQL · Bootstrap · JavaScript · Chart.js
